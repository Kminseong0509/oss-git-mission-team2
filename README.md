# 저장소 구조
이 저장소는 오픈소스SW및협업실무 Git 협업 미션을 진행하기 위해 구성되었습니다.

- `README.md`: 저장소의 목적과 전체 설명을 작성하는 파일입니다.
- `TEAM.md`: 팀명, 팀원 정보, 역할 등을 정리하는 파일입니다.
- `CONTRIBUTING.md`: branch, commit, Pull Request, review 규칙을 정리하는 파일입니다.
- `docs/`: Git 사용 규칙, 충돌 기록, 오류 기록, 명령어 정리를 보관하는 폴더입니다.
- `members/`: 팀원별 자기소개와 개인 Git 실습 내용을 작성하는 폴더입니다.
- `weekly/`: 주차별 미션 진행 상황과 기록을 정리하는 폴더입니다.

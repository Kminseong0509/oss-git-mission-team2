### 내가 겪은 오류 또는 어려웠던 점
- 처음에는 `git push origin weekly/CONTRIBUTING.md`처럼 파일 이름을 push하려고 해서 오류가 발생했습니다.
- `git push origin 브랜치명` 형식으로 push해야 한다는 것을 알게 되었습니다.
- 바깥 폴더와 안쪽 저장소 폴더가 헷갈려서 `git status` 결과를 해석하는 데 어려움이 있었습니다.
- `nothing to commit, working tree clean` 메시지를 보고 commit할 변경 사항이 없다는 의미를 알게 되었습니다.

### 해결 방법
- `git status`로 현재 상태를 먼저 확인했습니다.
- `git branch --show-current`로 현재 branch 이름을 확인했습니다.
- CONTRIBUTING.md 파일이 있는 실제 저장소 폴더로 이동한 뒤 작업했습니다.
- push할 때 파일명이 아니라 branch 이름을 사용했습니다.

### 사용한 Git 명령어
```bash
git status
git branch
git branch --show-current
git add CONTRIBUTING.md
git commit -m "weekly: update contributing guide"
git push -u origin weekly/update-contributing
